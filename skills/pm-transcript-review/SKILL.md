# 执行记录复盘

读取原始输入、可见执行步骤、工具响应、实际 Outcome 与评分规则；不要求或推测模型隐藏思维。没有记录时只列缺失证据，不给确定归因。

## 分析

1. 按时间找到首次偏离目标或约束的步骤，引用 Trial／步骤／证据定位。最后回复与实际结果不符时分别说明。
2. 每条失败选一个主因，可补次因：Agent 决策、检索／知识、工具／接口、运行环境、任务不清、评分器错误或证据不足。正确资料未检索到，与已取到却错误使用分开。
3. 区分观察到的事实与原因假设，给出能验证原因的最小检查。模型表达笃定不能替代证据。
4. 抽查边缘通过与正常相邻案例，检查是否偶然成功、过度操作、误报或过度拒绝。
5. 将修复项指向 Prompt、数据、工具、产品规则或评分器；评分规则变化单独版本化，不能用放宽门槛伪装产品改善。
