每个任务计划运行三次，模拟文件共十二条：十条通过、一条关键失败、一条环境错误。汇总会同时显示关键门槛 failed 与运行 incomplete，已评分通过率为 10/11。这说明高平均分不能掩盖关键失败，也不能把环境错误算成已评分结果。

真实接入时需补齐 fixture、执行器、可核查 Transcript／Outcome、评分器校准和已批准阈值。演示 URL `demo://` 不用于真实结果。
